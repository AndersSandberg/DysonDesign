#Dyson Sphere Design

Simulation software for the stability and construction of Dyson swarms.

## Projects

* **`solar_system_stability_map.py`** — orbital stability map (MEGNO) over (a, i)
  space for test particles / solar-sail bodies.
* **`gyroid_curve/`** — generative-art pipeline that fills a gyroid block with a
  single homogeneous surface-filling curve guided by a 3-D Hilbert sweep. See
  [`gyroid_curve/README.md`](gyroid_curve/README.md). Quick start:
  `python run_gyroid.py --method tsp --N 4 --delta 0.5`.
